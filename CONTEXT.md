# Luinbytes Site Redesign

Glossary for the motion-led redesign of the luinbytes portfolio site.

## Language

**Command Deck**:
The selected redesign direction: a portfolio experience organized around fast command-style search, selection, inspection, and launch actions.
_Avoid_: Terminal clone, fake shell, dashboard

**Control Surface**:
The selected Command Deck variant: a professional command-center interface for inspecting shipped work without pretending to be a literal terminal.
_Avoid_: Terminal Narrative, Dock Console

**Obsidian Pink**:
The selected palette direction: a dark cinematic base with pink used as a sharp recognition and focus color.
_Avoid_: Roseprint, pastel pink, soft glass

**Heavy Motion**:
The selected motion intensity: choreographed section transitions, command-surface movement, and selected-work morphs that make the site memorable while keeping routine UI interactions fast.
_Avoid_: Constant idle motion, toy-like animation, Very Heavy Motion

**Proof Loop**:
The selected homepage model: the visitor learns the repeated process of problem, build, verify, and ship before exploring individual work.
_Avoid_: Work Index, Failure Surface

**Annoyance Promise**:
The selected hero promise: "I get annoyed, then I build the missing thing." It is the remembered sentence, with the Proof Loop underneath to make the claim credible.
_Avoid_: Proof Promise, Command Promise

**Proof Rail**:
The selected case inspection shape: a chosen build opens into a four-step rail that walks through problem, build, verify, and ship.
_Avoid_: Inspection Drawer, Full Takeover

**Primary Surface**:
The selected command/search role: the command surface is visible in the first viewport and drives project selection while the page still tells the story.
_Avoid_: Launcher, Portfolio OS

**Proof Tabs**:
The selected mobile model: mobile emphasizes tappable proof-loop stages while command/search becomes a compact launcher.
_Avoid_: Compact Command, Scroll Story

**Light Proof**:
The selected evidence depth: each case gets a concise outcome line and links, while still preserving at least one concrete proof signal so the Proof Loop remains credible.
_Avoid_: Curated Proof, Deep Proof, vague proof claims

**GSAP Hybrid**:
The selected animation technology approach: use GSAP for timeline and scroll choreography only, while keeping ordinary UI interactions in CSS or Framer Motion.
_Avoid_: GSAP everywhere, Canvas Field, Framer-only motion

**Full Site Redesign**:
The selected implementation scope: apply the new visual system to the homepage, case routes, `luinbytes.github.io` link dock, and shared global shell.
_Avoid_: Homepage Only, Home + Link Dock
