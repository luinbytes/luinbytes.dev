# Ink-and-Paper Portfolio Pivot Map

## Destination

Redesign the homepage and all retained case pages around a unified ink-and-paper editorial pixel-print system, while preserving approved routes, current content truth, accessibility, and the phone-preview gate.

## Reference

- `docs/design-references/ink-paper-pixel-print-reference.jpg` is the visual reference for every design and review pass. Use it as a direction, not a branded copy.

## Decisions so far

- The pivot covers the homepage and all retained case pages.
- The old pink-noir visual language is replaced rather than blended with the new direction.
- The reference informs a non-infringing design language: ink black, warm paper yellow, faded mustard, hard graphic framing, pixel-display typography, mono utility copy, and alternating light/dark chapters.
- Current portfolio content, retained routes, and the approved theme/route cleanup scope stay intact.
- Motion is print-like and staged: registration, pixel resolution, and deliberate settling. It must remain readable from first paint on phone.

## Open design decisions

- Exact typography sources that achieve a bitmap/display character without sacrificing readable body copy.
- How strongly case pages invert between paper and ink while keeping content-scanning reliable.
- Which reference motifs become one signature recurring device rather than decorative repetition.

## Out of scope

- Copywriting new project claims or inventing evidence.
- Restoring deleted routes or the theme switcher.
- Changing the live site before a real production-export preview is approved on phone.
